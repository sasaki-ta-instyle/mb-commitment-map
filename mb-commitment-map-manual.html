1. ダッシュボードの見方

本編 URL: https://mb.instyle.group/html/mb-commitment-map.html

2 タブ構成

  • コミットメントマップ: 左右対称のあみだくじ図。中央に部署 (モール / 本店 / CS / 商品)、左に定量目標、右に定性目標がぶら下がる
  • マイルストーン: 作戦ごとの月次目標・実績・達成率をテーブル表示

部署カラー

部署ごとに色が割り当てられている。線の色でどの部署の指標か一目でわかる。

  • モール (マーケ:モール)
  • 本店 (マーケ:本店)
  • CS
  • 商品

色は 凡例 タブで変更できる。

ボックスの階層

左右対称に 成果 → 作戦 → 詳細 の順で並ぶ。中央の部署ノードから外側に広がる形。

  • 成果 (最も淡い) — 部署単位の中核成果。複数の作戦が紐付く
  • 作戦 (中間) — 成果を達成するための中目標。複数の詳細が紐付く
  • 詳細 (最も濃い) — 実行単位の小タスク。1 行 = 1 詳細

2. スプシの構成 (タブ一覧)

スプシは Sheets を master、HTML を読取専用ビュー として動く。編集はスプシで完結し、HTML はキャッシュなしで最新を fetch する。

タブ名役割編集頻度
コミットメントリスト本体データ。1 行 = 1 詳細 (小タスク)頻繁
戦略的フォーカス左右の大目標と列ラベルを保持 (2 行のみ)稀
凡例部署カラー (4 部署 × 色コード)ほぼ変えない
マイルストーン作戦ごとの月次目標/実績を保持月次
連携部署をまたぐ関連 (別タブ版、コミットメントリストの 連携 列と併用可)随時
_members担当者プルダウンの正本 (hidden)人員変更時
_progress進捗プルダウンの正本 (hidden)ほぼ変えない
命名規則 _ プレフィックス タブは Google Sheets の UI 上で hidden 表示にしている。プルダウンの選択肢正本として使う。編集する時はタブ右クリック → 「シートの再表示」で出せる。

ヘッダー名は日本語・英語どちらでも動く (alias 対応)。列の物理位置も変えられる (ヘッダー名で列を引くため)。

4. よくある操作

新しい詳細行を追加する

  1. コミットメントリストの末尾に新しい行を追加
  2. A 列に新しい ID (連番) を入れる (例: C-201)
  3. サイド / 部署 / サブ部署 / 成果 / 作戦 / 詳細 を埋める
  4. 担当・期日・進捗をドロップダウンから選ぶ
  5. 本編ページで ↻ 再読込 を押すか、ページをリロード

同じ成果・作戦を繰り返し書けば、既存ノードに自動で紐づけられる (合流)。

担当者を追加する

  1. スプシ左下のタブメニュー (▼) → 「シートの再表示」 → _members を出す
  2. A 列の末尾に新しい名前を追加
  3. 再び hidden に戻す (タブ右クリック → 「シートを非表示にする」)
  4. これで 担当 / 最終編集者 列のドロップダウンに追加される

部署カラーを変える

  1. 凡例 タブを開く
  2. C 列 (color_hex) を #RRGGBB 形式で書き換える
  3. 本編でリロード
制約 色コードは #RGB または #RRGGBB のみ有効。それ以外は自動で #888 にフォールバックされる。

大目標 / 戦略的フォーカスを変える

ヘッダーの「戦略的フォーカス：定量」ラベルや、左右の goal box の文言 (「2027 年 3 月末までに / 利益 1 億円」など) を編集する場合:

  1. 戦略的フォーカス タブを開く (2 行しかない、定量 / 定性)
  2. B 列: フォーカスラベル (列の頂上に出る文字)
  3. C 列: 目標サブ (goal box の上段、小さい文字)
  4. D 列: 大目標 (goal box の下段、大きい文字)
  5. 本編でリロード

部署をまたぐ関連 (連携線) を追加する

2 通りの書き方がある。どちらでも同じ線が描かれる。

方法 A: コミットメントリストの 連携 列 (I) に書く

その行を起点にして、繋げたい先を列挙。1 セルに複数書ける (改行 or カンマ区切り)。

C-101
C-102
本店/LP 転換率改善
  • C-xxx → 詳細 ID を指定 → その詳細ボックスに繋がる
  • <部署>/<作戦> → 作戦単位に繋がる (例: 商品/9 月同時発売キャンペーン)
  • <部署>/<成果> → 成果単位に繋がる

方法 B: 連携 タブに書く

from / to を独立した 2 列で指定。関連が多くて行単位で書き切れないときに便利。

連携①連携②
C-004C-101
商品/9 月同時発売キャンペーン本店/LP 転換率改善
連携線の表示ルール 通常は非表示。片側のボックスに hover した瞬間だけアクセント色 (teal) の破線で浮かび上がる。方向は無く、from-to が同じペアは重複除去される。

詳細ボックスに URL を貼る (別窓オープン化)

  1. コミットメントリスト の リンク 列 (H) にプレーンテキストで URL を貼る
  2. Notion ページ / Google ドキュメント / Google ドライブフォルダ 何でも OK
  3. URL が入った詳細ボックスにカーソルを乗せると 指マーク になり、クリックで別窓オープン
重要 Google Sheets の「リンクを挿入」機能 (Cmd+K) は使わないこと。表示テキストしか読み取れず URL が消える。プレーンテキストとして URL 文字列そのものをコピペする。

5. ハマりポイント

連携セルが日付書式になっている

症状: 連携列に C-102 と書いたのに console に 参照解決失敗 の warning が出て線が描かれない。

原因: セルの表示形式が「日付」になっていて、入力が Excel 日付シリアル値 (数字) に変換されている。

対処:

  1. 連携列 (I) のヘッダー「I」をクリックして列全体を選択
  2. メニューの 表示形式 → 数字 → 書式なしテキスト
  3. 問題のあるセルを一度 Delete で消してから C-102 を書き直す

URL をクリックしたら 404

チェックポイント:

  • URL が途中で切れていないか (セルをクリックして数式バーでフル文字列を確認)
  • 「リンクを挿入」機能を使っていないか (プレーンテキストで貼る)
  • Notion / Google Drive の閲覧権限が自分のアカウントにあるか
  • DevTools Console (Cmd+Option+I) に [commitment-map] open link: ... が出るので、その URL を直接ブラウザにコピペして開いて確認

スプシの共有権限を「メンバー個別」にしたら見えなくなった

HTML はスプシを匿名 fetch で読むため、公開レベルは 「リンクを知っている全員が閲覧」以上が必要。編集権限だけメンバー個別に付与、閲覧はリンク公開のまま、が正解。

編集したのに反映されない

  • 本編ページで ↻ 再読込 ボタン (右上) を押す
  • それでもダメなら Cmd+Shift+R (Mac) で強制リロード
  • スプシ側の編集が保存されているか確認 (Google Sheets は自動保存だが、ネットが切れると保留になる)

装飾行を 1 行目に書いても壊れないか

OK。戦略的フォーカス タブの 1 行目に「WE PROMISE!...」のような自由記述を置いても、HTML は「必須ヘッダーが揃った行」を自動検出するので影響なし。

6. FAQ

Q. スプシの列順を変えたら壊れる?

A. 壊れない。HTML は「ヘッダー名」で列を引くので、列の物理位置は自由に変えられる。

Q. ヘッダー名を英語 / 日本語どちらでも書ける?

A. どちらも OK。id ↔ ID、owner ↔ 担当、editor ↔ 最終編集者 など、alias が定義されている。

Q. 新しい部署を追加したい

A. 凡例 タブに新規行を追加 (key / label / color_hex / display_order を埋める)。コミットメントリストの部署列のドロップダウン正本を更新するには bootstrap-sheet.gs の applyValidations を書き換えて再実行。

Q. HTML を編集したい / 機能追加したい

A. GitHub リポジトリ: sasaki-ta-instyle/mb-commitment-map。ローカル編集 → scp で本番 /var/www/mb/html/ にデプロイ。

Q. マイルストーンタブに何を書けばいい?

A. 作戦ごとの月次目標値・実績値。1 行 = 1 作戦の 1 メトリック。strategy_id でコミットメントリストの ID と紐付ける。詳細は docs/sheets-schema.md の Tab 2 参照。
